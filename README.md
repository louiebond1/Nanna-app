# Nanna Games

A private, two-player browser games app for Nanna and her grandson. Two devices join one private room with a link or short code, then play cards, word, deduction, strategy and memory games.

**Status:** planning (Phase A). Nothing is playable yet. See [docs/PLAN.md](docs/PLAN.md) for the architecture, the proposed rules for each game, the open decisions and the progress ledger.

Planned stack: Node 22, Express, Socket.IO, SQLite (`node:sqlite`), `node --test`, deployed on Railway.
